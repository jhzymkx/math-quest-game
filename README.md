# 數學森林大冒險

使用 Phaser 3.88.2 製作的國小數學闖關遊戲，共五個關卡。Phaser 引擎已放在專案資料夾內，不需安裝套件或啟動伺服器。

## 開始遊戲

用瀏覽器開啟 `index.html`。

## 遊戲方式

- 使用方向鍵或 WASD 移動小狐狸，碰到正確答案即可過關。
- 每題答對加 10 分，答錯扣 5 分；答錯後可繼續找同一題的正解。
- 每關答對後會產生新題目。題型依序為加法、減法、乘法、除法和兩位數加法；同一瀏覽器工作階段內，同關題目不重複。
- 手機或平板可使用畫面上的方向鍵。

## 專案檔案

- `index.html`：遊戲頁面與操作介面。
- `game.js`：Phaser 場景、題目生成、移動與計分邏輯。
- `style.css`：頁面排版與行動裝置樣式。
- `phaser.min.js`：本機 Phaser 3.88.2 引擎。
